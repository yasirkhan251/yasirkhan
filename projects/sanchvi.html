01 · OVERVIEW

What is Sanchvi?

What the project does

Sanchvi is an online-store application rather than a simple product catalogue. The codebase connects the customer-facing shopping journey with product data, cart state, shipping information, order records and payment flows.

How it benefits the user/business

  • Provides an end-to-end shopping workflow in one application.
  • Supports size, colour and pricing variations for products.
  • Connects checkout, shipping and order tracking concepts.
  • Demonstrates practical Django models, views, templates and payment integration.

Platform & environment

Web application — Django/Python backend with server-rendered templates and SQLite for development.

04 · BACKEND

What role does the backend play?

The backend/application layer is responsible for connecting the interface to the project's data, business logic and user workflows.

  • Models hold products, prices, colours, images, carts, orders, order items and shipping data.
  • Authentication is handled through a custom user model and account views.
  • Payment views connect the checkout state with PhonePe/PayPal flows.
  • Admin views provide product/category and operational management.
  • The backend turns the storefront into a data-driven application rather than a static catalogue.
05 · USAGE

How is it used?

A customer can register, browse the catalogue, choose product variations, add items to a cart, enter delivery information, select a payment method, and then review order status/history.

Project maturity: Substantial. The purpose of this page is to explain the implementation that exists in the repository, while keeping production-readiness claims separate.
